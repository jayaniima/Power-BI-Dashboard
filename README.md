# 📊 Electric Capital Portfolio Oversight Dashboard

## Overview

The Electric Capital Portfolio Oversight Dashboard is a Power BI reporting solution designed to provide comprehensive visibility into capital project performance across a portfolio. The dashboard enables stakeholders to monitor key performance indicators, track project progress, analyze budget utilization, and support data-driven decision-making through interactive visualizations.

---

## Business Challenge

Managing a portfolio of capital projects requires timely access to reliable information on project status, financial performance, and schedule adherence. Traditional reporting methods often make it difficult to quickly identify risks, monitor trends, and prioritize actions.

This dashboard addresses these challenges by consolidating project data into a centralized, interactive reporting platform that supports both strategic oversight and operational decision-making.

---

## Objectives

- Provide a portfolio-level view of project performance
- Monitor project status and progress
- Track budget and cost performance
- Analyze schedule and milestone completion
- Identify projects requiring management attention
- Support executive reporting and decision-making
